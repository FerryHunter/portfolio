Web3 Game Deployer Engine

Lima perintah World CLI berubah jadi satu game shard onchain. Saya mendesain dashboard yang menampilkan prosesnya: daftar, sambungkan chain, deploy, dan lihat statusnya berubah dari pending ke live tanpa keluar dari browser.

Ringkasan

01 · Brief-nya

World Engine adalah framework ECS dan tick-driven untuk game onchain real-time, lebih dekat ke Unity atau Unreal ketimbang tooling blockchain pada umumnya. State tiap shard hidup di chain yang selalu bisa dijangkau studio, bukan di server satu perusahaan. Meluncurkan satu shard tetap lewat terminal: lima perintah CLI, tanpa satu pun tampilan bersama soal apa yang sudah benar-benar ter-deploy. Saya mendesain dashboard di sekeliling CLI itu: daftar, buat world, dan lihat satu shard jadi live.

Masalah

02 · Titik rusaknya

Deploy satu game shard berarti membaca dokumentasi di satu tab dan terminal di tab lain.

World CLI bisa menyalakan satu game shard dalam lima perintah, tapi dashboard di sekelilingnya berhenti di halaman daftar: tidak ada status shard, tidak ada chain ID, tidak ada cara membedakan base shard yang deploy mulus dari game shard yang gagal diam-diam. Satu-satunya umpan balik adalah menjalankan ulang perintah deploy dan menonton terminal bergulir.

Setiap deployment memunculkan tiga pertanyaan yang sama tanpa satu tempat untuk menjawabnya: chain ini live atau tidak, berjalan di atas apa, dan commit mana yang tayang. Menjawabnya berarti menyilangkan block explorer, log CLI, dan satu thread Discord.

Premis Cardinal adalah state satu shard tidak hidup di infrastruktur satu tim seperti server Nakama: kehilangan akun yang mengelola server berarti state game ikut hilang, tapi game shard yang tertaut ke blockchain tetap bisa dijangkau lewat chain itu sendiri. Tidak satu pun dari itu terlihat di dashboard. Studio tidak punya cara untuk melihat sekilas bahwa chain ID dan block height shard mereka adalah jaminan nyata, bukan sekadar baris log dari CLI yang harus dipercaya begitu saja.

Pendekatan

03 · Cara kerjanya

Satu kartu overview untuk vital sign shard, satu checklist terpandu untuk lima perintah yang membuatnya.

Tab Overview menampilkan EVM chain ID, RPC URL, tautan block explorer, dan block height satu game shard begitu ia live, dengan status pill (Success, Running, Failed) menggantikan tugas log terminal mentah. Detail chain yang sama itu juga jadi jalan masuk kembali kalau studio pernah kehilangan akses ke World Engine itu sendiri: state shard hidup di chain, bukan di server satu tim, jadi chain ID dan tautan explorer sudah cukup untuk menjangkaunya secara mandiri.

Create your World mengubah lima perintah World CLI, login, create, link, evm deploy untuk chain dasarnya, cardinal deploy untuk logika dan state game shard itu sendiri, jadi checklist yang bisa disalin di sebelah dokumentasinya, sehingga developer mengikuti urutan yang sama baik ia membaca panduan atau layarnya.

Recent Deployments mendaftar setiap shard berdasarkan branch, commit, environment, dan author, bisa disaring lewat rentang tanggal dan status, sehingga deploy yang gagal tinggal satu pandangan dari yang berhasil di sebelahnya, bukan di tab berbeda.
